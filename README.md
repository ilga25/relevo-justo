# Relevo Justo

Organiza tramos de juego con suplentes y calcula los minutos de cada participante. Rotación cíclica, tabla de cambios y diferencias visibles, sin registro.

GitHub Pages: main, raiz. https://ilga25.github.io/relevo-justo/

Fuentes estaticas sin dependencias. Pruebas del motor: work/ten-tools/check.cjs. Guia propia, privacidad y sitemap incluidos. Sin garantia de trafico, indexacion, aprobacion publicitaria o ingresos.
